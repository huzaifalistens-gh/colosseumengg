# Unified visual system

Manrope is self-hosted in weights 400, 600 and 700 throughout all eight pages. Brand colors, type sizes, spacing, radii and motion timings are centralized in dist/assets/styles.css.

- Container: 1240px; gutters: 40px desktop, 28px tablet, 18px mobile.
- Section spacing: 104px desktop, 80px tablet, 64px mobile.
- Cards: 10px corners, fine border, restrained hover shadow. Buttons: 7px corners.
- Images: civil engineering stock photography, consistently cropped with subtle corners. Project cards use 3:2; detail hero uses 2:1 desktop and 3:2 mobile.
- Icons: local Lucide SVGs with consistent strokes; license included in assets/icons.
- Motion: 500ms section reveals, 70ms stagger, 220ms button transitions; reduced-motion overrides included.
- Mobile: centered content and tags, one-column cards, icon-only navigation sheet, vertical approach timeline.
- Desktop: editorial alignment, structured service and project grids, horizontal approach timeline.

## Audit and resolution

Before editing, screenshots of Services and a project detail page showed a mismatch between the newer hero and the older typography, narrow service columns, and project-image treatment. The shared stylesheet now owns all visual rules, and all detail pages use the same heading, tag, image and button components as the homepage. Original five approach steps, exact logo and documented project facts remain intact.

Contact retains working email, phone and WhatsApp links. No form backend was supplied; no simulated submission was added.

Font licensing is included in assets/fonts; photo credits and factual source notes are in this docs folder.
